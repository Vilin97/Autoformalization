**Key Proof Idea:**
- For U = ⊥: F(⊥) is zero, so any map to it is epi.
- For U ≠ ⊥: By naturality of the sheafification unit η and the fact that the constant presheaf has identity restriction maps, we get η_U = η_V ≫ res. If η_U is epi, then res is epi by `epi_of_epi`. The constant presheaf satisfies the sheaf condition at nonempty opens (proven in lemma 4), which should imply the sheafification unit is epi at those opens.

**Remaining difficulty:** The core challenge is lemma 5 (`sheafificationUnit_epi_of_nonempty`), which requires showing that the sheafification of a presheaf that satisfies the sheaf condition at specific objects has an iso sheafification map at those objects. The constant presheaf fails the sheaf condition at ⊥ (the empty sieve requires sections to be a singleton, but Hom(ℤ,ℤ) ≅ ℤ), so the global version cannot be applied.
