\begin{abstract}
This is the implementation plan for a kernel-checked Lean proof of the
McKay equality.  It is intentionally not a survey and not a claim that the
proof is finished.  The shortest current route is hybrid: keep the
classification and universal-cover verification required by the published
proof, but replace the projective/Dade-theoretic normal-subgroup seam by the
ordinary per-parameter counting chain obtained from classical Gallagher
counting, the original Okuyama--Wajima criterion, and normal-product
restriction \cite{Murray2023,Navarro2018,OkuyamaWajima1980}.  A source audit found that
the tempting equivariant shortcut in Maltempo--Vallejo
\cite{MaltempoVallejo2026} is false as printed, so it is explicitly excluded
from the dependency graph.  The document records the exact existing Lean
boundary, what is complete, what remains open, and the compile gate for every
major phase.
\end{abstract}

\section{Target, trust boundary, and operational invariants}

\subsection{Exact public target}

For a finite group \(G\), a prime \(p\), and \(P\in\Syl_p(G)\), the target is
\[
  |\Irr_{p'}(G)|=|\Irr_{p'}(\Norm_G(P))|.
\]
The proposition already in the repository is
\path{McKayConjecture.Statement}:

\begin{lstlisting}
def Statement (G : Type u) [Finite G] [Group G]
    (p : Nat) [Fact p.Prime] (P : Sylow p G) : Prop :=
  Cardinal.mk (PPrimeIrreducibleCharacter G p) =
    Cardinal.mk
      (PPrimeIrreducibleCharacter (SylowNormalizer P) p)
\end{lstlisting}

The final export should have no mathematical hypothesis beyond this
signature.  The planned endpoint is:

\begin{lstlisting}
theorem McKayConjecture.mckay
    (G : Type u) [Group G] [Finite G]
    (p : Nat) [Fact p.Prime] (P : Sylow p G) :
    McKayConjecture.Statement G p P
\end{lstlisting}

Changing the final theorem name is harmless; weakening its type is not.
In particular, a theorem conditional on a reduction hypothesis, a CFSG
coverage predicate, or family-verification data is an intermediate
milestone and not the deliverable.

\subsection{Trust invariants}

\begin{invariant}[No hidden theorem]
No required reduction, classification, family theorem, or character-table
fact may enter through \texttt{axiom}, \texttt{sorry}, \texttt{admit}, an
empty \texttt{opaque}, a fabricated instance, or inconsistency.  Interface
predicates are permitted only while they remain visibly quantified
hypotheses of intermediate theorems.
\end{invariant}

\begin{invariant}[Reported trusted computing base]
The final audit must run \texttt{\#print axioms} on the exported theorem and
report every dependency.  Standard Lean/mathlib principles such as
propositional extensionality, quotient soundness, and classical choice are
acceptable.  This repository also currently contains 282
\texttt{native\_decide} occurrences in 42 Lean files.  Native decision
procedures therefore form part of the present computational trust boundary;
they must not be described as pure kernel reduction, and generated table
data must still be connected to mathematical objects by checked theorems.
\end{invariant}

\begin{invariant}[Default heartbeats]
Do not set or raise \texttt{maxHeartbeats}.  Split expensive proofs and
large computations into named lemmas and separately compiled files.
\end{invariant}

\begin{invariant}[Exact mathematical boundary]
The numerical shortcut below is used only for the solvable
normal-subgroup seam.  It does not license omitting the quasisimple
inductive-McKay verification or CFSG coverage.
\end{invariant}

\subsection{Build and push invariants}

\begin{enumerate}[label=\textbf{B\arabic*.},leftmargin=*]
  \item A failed \texttt{lake build} is priority zero.  Stop new
  mathematical work, identify the first failing module, restore a full
  build, and only then continue.
  \item Run a targeted module build after each leaf milestone and a full
  \texttt{lake build} after each major phase.  Never start duplicate full
  builds.
  \item A phase is not complete merely because its leaf file builds:
  its umbrella import and the full package must also build.
  \item Before a push, require a green full build, a clean placeholder
  audit, and a reviewed diff.  While work continues and there are changes,
  push on a twelve-hour cadence, never at intervals shorter than twelve
  hours; record the last push time.
  \item LaTeX must build independently of Lean and must not contain claims
  stronger than the declarations it names.
\end{enumerate}

\section{Proof-route decision}

\subsection{Literature correction: do not use the equivariant count}

Maltempo--Vallejo Theorem~1.3 is false as printed and is not an admissible
formalization dependency.  A concrete counterexample is
\[
 A=S_3,\qquad G=A_3,\qquad N=1,\qquad \theta=1.
\]
Every element of \(A_3\) is \(\theta\)-good: for a nonidentity element,
\(N\langle a\rangle=A_3\) and its relevant centralizer is \(A_3\), whose
conjugation action is inner; the identity is immediate.  Nevertheless,
only the trivial member of \(\Irr(A_3)\) is fixed by \(S_3\).  Thus the
fixed-character side has size \(1\), while the three intrinsic conjugacy
classes of \(A_3\) are good.  Even the alternative reading ``\(S_3\)-classes
contained in \(A_3\)'' gives \(2\), not \(1\).

The failure is visible in the published proof: it asserts that restriction
from \(A\) lands in the span of the individually \(A\)-fixed irreducibles of
\(G\).  The degree-two irreducible character of \(S_3\) restricts to
\(\omega+\omega^2\) on \(A_3\), which is an orbit sum and is not in the
span of the fixed trivial character.  The proof also changes between
intrinsic \(G/N\)-classes and ambient \(A/N\)-classes contained in \(G/N\).
Consequently Theorem~1.3, Corollary~1.4, and the equivariant Corollary~2.3
and Equation~(2.1) of \cite{MaltempoVallejo2026} must not be invoked unless
a corrected theorem is supplied independently.

The needed Lean boundary is fortunately ordinary rather than equivariant.
The replacement below reconstructs only the valid self-action argument from
Gallagher's original commutator-sum proof, in the streamlined form explained
by Murray, and the original Okuyama--Wajima proof
\cite{Gallagher1971,Murray2023,Navarro2018,OkuyamaWajima1980}.

This replaces, at the normal-subgroup seam only, the route through

\subsection{Exact ordinary inertia-group specialization}

Fix data quantified by the current cardinality boundary:
\[
\begin{gathered}
X\text{ finite},\quad S\in\Syl_q(X),\quad C\trianglelefteq X,\\
C\cap S\leq Z(X),\qquad X=C\,\Norm_X(S).
\end{gathered}
\]
Set
\[
\begin{aligned}
R&=O_{q'}(C),&
L&=RS=CS,\\
H_0&=\Norm_X(S),&
R_0&=\Cent_R(S),\qquad \Norm_L(S)=R_0S.
\end{aligned}
\]
In Lean, \(R\) is
\path{ambientNormalIntersectionComplement S C hcentral},
\(L\) is \path{product S C}, \(H_0\) is
\path{Subgroup.normalizer (S : Set X)}, and the internal copy of
\(\Norm_L(S)=R_0S\) is \path{internalProductNormalizer S C}.
Existing group theory supplies \(R\trianglelefteq X\), the \(q'\)-order of
\(R\), normality of \(L\), \(X=RH_0\), and the displayed normalizer
description.  Theorem~4.4 coordinates instead use the internal subgroup
\path{productPPrimeKernel S C}; the existing ambient/internal equivalence
must be used whenever a theorem changes coordinates.

Fix \(\theta\in\Irr_{q'}(L)\), and let
\(r\in\Irr(R)\) be the canonical \(S\)-invariant constituent selected by
its active Clifford orbit.  Two inertia groups must be kept distinct:
\[
  \Delta=I_X(r),\qquad \Gamma_\theta=I_X(\theta).
\]
The character \(\theta\) is an extension of \(r\), hence
\(\Gamma_\theta\leq\Delta\); in general \(\theta\) is not
\(\Delta\)-invariant.  The abstract per-character OW count must therefore
be instantiated in \(\Gamma_\theta\), not in \(\Delta\).
\path{productOkuyamaWajimaInertia} is the already implemented full
kernel-character inertia \(\Delta\).  Inside the exact group
\(\Gamma_\theta\), use
\path{inertiaSubgroupCopy} to form the characteristic copy \(K_\theta\)
of \(R\), and use
\path{productAmbientGlaubermanLeftInertiaSylow} for the restricted copy
of \(S\).  Since \(S\leq L\) acts by inner automorphisms,
\(S\leq\Gamma_\theta\), so it remains Sylow there; moreover
\(K_\theta S\) is the normal copy of \(L\).

Let \(\theta^*\) be the existing Theorem~4.4 image.  Its established
equivariance and injectivity give the canonical equivalence
\[
 I_{H_0}(\theta^*)\simeq\Norm_{\Gamma_\theta}(S),
\tag{I}
\]
implemented by
\path{productAmbientGlaubermanRightInertiaEquivLeftSylowNormalizer}.
The two groups inhabit different subtype ambient types, so (I) must not be
stated as literal Lean equality.

The source extension \(\theta\) of \(r\) and the target extension
\(\theta^*\) of its Glauberman correspondent \(r^*\) have independent
Gallagher decompositions
\(\theta=\widehat r\,\mu\) and
\(\theta^*=\widehat{r^*}\,\nu\).
Thus every character count below is an ordinary self-action count; there
is no external automorphism group and no fixed-character subtype.

The replacement proof has four semantic layers.

\begin{enumerate}[label=\textbf{O\arabic*.},leftmargin=*]
  \item \emph{Classical Gallagher count.}
  For \(N\trianglelefteq A\) and \(A\)-invariant
  \(\theta\in\Irr(N)\), prove
  \[
    |\Irr(A\mid\theta)|
      =\#\{\text{\(\theta\)-good conjugacy classes of \(A/N\)}\}.
    \tag{G}
  \]
  The general ordinary count is Navarro Theorem~5.16.  For formalization,
  use Gallagher's original commutator-sum proof rather than first proving
  the central-faithful restriction-map theorem and then constructing a
  strong character-triple transport.  The direct proof needs only
  restriction multiplicities, Schur orthogonality, the torsor of extensions
  across a cyclic quotient, and finite-character orthogonality
  \cite{Gallagher1971}; Murray gives a particularly explicit account of
  this method \cite[\S2]{Murray2023}.  This is not the false external-action
  generalization.

  \item \emph{Ordinary Okuyama--Wajima comparison.}
  Let \(K\trianglelefteq A\) be a \(q'\)-group, let \(S\) be a
  \(q\)-subgroup with \(KS\trianglelefteq A\), and let
  \(r\in\Irr(K)\) be \(A\)-invariant.  Put \(D=\Cent_K(S)\), and let
  \(r^*\) be its Glauberman correspondent.  Glauberman equivariance makes
  \(r^*\) invariant under \(\Norm_A(S)\).  For each
  \(D\leq U\leq\Norm_A(S)\), prove
  \[
    |\Irr(KU\mid r)|=|\Irr(U\mid r^*)|.
    \tag{OW}
  \]
  The quotient equivalence \(U/D\simeq KU/K\) preserves conjugacy and,
  by the required application specialization of the original
  Okuyama--Wajima extension criterion, preserves goodness.
  Applying (G) on the two sides proves (OW).

  \item \emph{Base canonical-extension count.}
  Abstractly, let \(K\) be a \(q'\)-group,
  \(KS\trianglelefteq\Lambda\), and let \(r\) be
  \(\Lambda\)-invariant.  In the exact application
  \(\Lambda=\Gamma_\theta\).  Choose a Schur--Zassenhaus complement
  \(U/D\) to \(DS/D\) in \(\Norm_\Lambda(S)/D\).  Frattini and the
  normal-product
  identities give
  \[
  \Lambda=(KS)(KU),\quad (KS)\cap(KU)=K,\qquad
  \Norm_\Lambda(S)=(DS)U,\quad (DS)\cap U=D.
  \]
  The semantic normal-product restriction theorem (Navarro
  Lemma~6.8(d)) then gives equivalences
  \[
  \begin{aligned}
    \Irr(\Lambda\mid\widehat r)&\simeq\Irr(KU\mid r),\\
    \Irr(\Norm_\Lambda(S)\mid\widehat{r^*})
      &\simeq\Irr(U\mid r^*).
  \end{aligned}
  \]
  Combining these with (OW) yields equality of the two base-fibre
  cardinalities.

  \item \emph{Independent twisting and the exact adapter.}
  Write
  \(\theta=\widehat r\,\mu\) and
  \(\theta^*=\widehat{r^*}\,\nu\) in their respective Gallagher
  coordinates.  Invariance in the two inertia groups makes \(\mu\) and
  \(\nu\) invariant.  Descend \(\mu\) to the normal Sylow \(q\)-subgroup
  \(KS/K\) of \(\Gamma_\theta/K\).  Since
  \((\Gamma_\theta/K)/(KS/K)\simeq\Gamma_\theta/KS\) has \(q'\)-order,
  the invariant linear character extends to \(\Gamma_\theta/K\); inflate
  this extension to \(\Gamma_\theta\).  Apply the same argument to the
  normal Sylow subgroup
  \(DS/D\) of \(\Norm_{\Gamma_\theta}(S)/D\) and the target parameter
  \(\nu\).
  Twisting identifies each displayed fibre independently with its base fibre.
  No equality \(\nu=\mu^*\), no covariant choice of linear extension, and
  no external fixed-character theorem is required.  Apply (I) and the
  existing subgroup transports to obtain exactly
  \[
  \begin{split}
  &\operatorname{Nat.card}
    (\path{IrreducibleCharactersOverInertia L theta})\\
  &\qquad =
    \operatorname{Nat.card}
    (\path{IrreducibleCharactersOverInertia
      (internalProductNormalizer S C) thetaStar}).
  \end{split}
  \tag{F}
  \]
\end{enumerate}

The endpoint (F) is ordinary.  Navarro's degree theorem
\cite[Theorem~5.12]{Navarro2018} is a separate adapter.  Its precise
divisibility is
\[
  \frac{\chi(1)}{\theta(1)}\mid |G:N|
  \qquad(\chi\in\Irr(G\mid\theta)).
\]
It must be applied with \(G=I_X(\theta)\), so the controlling order is the
\emph{inertia quotient} \(|I_X(\theta):N|\), not the ambient induction
index \(|X:I_X(\theta)|\).  In the present application the normal
characters have \(q'\)-degree and the two inertia quotients have
\(q'\)-order, hence the theorem implies that every ordinary character in
both fibres has \(q'\)-degree.
\path{Character/NavarroRelativeDegreeDivisibility.lean} now proves this
universal relative-degree divisibility theorem, and
\path{NormalSubgroupCentralIntersectionAutomaticDegree.lean} discharges
the exact two fibre-degree hypotheses from the already proved
quotient-order facts.  This isolates the ordinary cardinality equality as
the only character-theoretic input at this boundary; the canonical
Okuyama--Wajima assembly and exact-inertia relabelling now discharge it.
Finiteness and
\texttt{Finite.card\_eq.mp} convert a final cardinality equality to an
equivalence only where the downstream join-center proof requests one.

\subsection{Why the per-parameter proof must remain explicit}

The current Lean boundary asks for the cardinality of each matched
Clifford inertia fibre, for every \(\vartheta\).  An equality obtained only
after summing over Gallagher parameters does not imply equality of each
summand.  The implementation must therefore expose the base count and the
two independent twist equivalences before any aggregate sum.  This is
precisely why the statement of Navarro Theorem~8.11, which is an aggregate
\(q'\)-count, is too coarse: the formalization needs the stronger
per-parameter steps in its proof.

\subsection{What remains outside the shortcut}

The shortcut applies because the required quotients are \(q\)-solvable.
The relative-degree step needs \(q'\)-order of the inertia quotient
\(I_X(\theta)/N\); a later ambient Clifford-induction step, if used, instead
needs \(q\nmid |X:I_X(\theta)|\).  These are different indices and must not
be interchanged.  The exact facts are listed in P1.E below.  In particular,
\path{productAmbientGlaubermanLeftOuterQuotient_isPPrimeGroup} concerns a
character-inertia quotient and is not a substitute for proving that the
ambient quotient \(X/L\) is \(q'\).  The shortcut does not prove any of
the following:

\begin{itemize}
  \item the inductive-McKay condition for universal covers;
  \item the \(A_6\) projective rows or any other family table;
  \item finite-reductive conditions \(\mathrm A(\infty)\),
  \(\mathrm A(d)\), or \(\mathrm B(d)\);
  \item the final type-\(D\) theorem; or
  \item the CFSG exhaustion.
\end{itemize}

  \item[\path{FiniteReductive/...}, \path{TypeD/...}, \path{CFSG/...}]
  Add only when their first independently compiling semantic object exists;
  do not create placeholder directory trees.

Use semantic theorem names for stable APIs.  Paper-number names may be
aliases next to the proof.  Whenever an intermediate result can be stated
using current mathlib or repository types, state it immediately: this makes
the dependency graph executable, gives Lean's elaborator a small target,
and prevents a long proof from hiding a mismatch at the final boundary.

\section{Definition of genuine completion}

The project is complete only when the unconditional, universe-polymorphic
\path{McKayConjecture.mckay} builds from a fresh pinned checkout and its
dependency report contains no project-specific assumption.  The following
are valuable but are not completion:

\begin{itemize}
  \item the current cardinality and quasisimple conditional theorems;
  \item the numerical \(A_6\) McKay equalities;
  \item an aggregate ordinary Okuyama--Wajima count without the
  per-parameter restriction and independent-twist steps;
  \item a family verification with finite table or projective data as an
  argument;
  \item a \path{CFSGFamilyCoverage} parameter; or
  \item a universe-zero theorem presented as the public
  universe-polymorphic statement.
\end{itemize}

The route in this blueprint minimizes the ordinary-group reduction burden,
but the classification and family verification remain a large formalization
project.  Keeping those boundaries explicit is part of the proof.
