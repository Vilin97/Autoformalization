# Global Steady State of the Vlasov-Maxwell-Landau System

This project formalizes the main result (Theorem 42) of [Guo & Strain, "Almost exponential decay near Maxwellian"](https://doi.org/10.1007/s00220-006-0100-y), characterizing the global steady state of the Vlasov-Maxwell-Landau system on a flat 3-torus.
